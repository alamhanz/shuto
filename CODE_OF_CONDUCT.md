# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Please read it; it applies to all project spaces (issues, pull requests, discussions).

In short: be respectful, welcome newcomers, give and accept feedback kindly, and do not harass
or discriminate against anyone.

## Reporting

To report unacceptable behavior, contact the maintainer, @alamhanz, through GitHub (a private
security advisory on this repository, or a message to the maintainer's profile). Reports are
handled privately.

## Enforcement

The maintainer may edit or remove comments, close issues and pull requests, or block users
who do not follow this code, following the enforcement guidelines in the Covenant.
