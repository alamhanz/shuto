usage: shuto models [-h] [--config CONFIG] [-v] {list,pull,use,bench} ...

list, choose, download and benchmark local models

positional arguments:
  {list,pull,use,bench}
    list                top 8 local models for this machine
    pull                download a model with Ollama (asks first)
    use                 remember your choice: TAG or PROVIDER:MODEL
    bench               time one model on a sample image

options:
  -h, --help            show this help message and exit
  --config CONFIG       path to shuto.yaml
  -v, --verbose
